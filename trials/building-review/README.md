# Pursuit building review

With Python 3.10+, double-click **Open Review.cmd** on Windows or run
`python serve.py --open` from this folder. Open <http://127.0.0.1:8767/> and leave
the terminal running; press Ctrl+C to stop. If needed, use
`python serve.py --port 8768 --open`. No packages need installing.

Drag to orbit, scroll/pinch to zoom, right-drag to pan, or choose a floor/route
stop. Use Download GLB for the full model. Keep this entire folder together when
copying it; it works independently of the rest of the repository.

The complete [building review guide](../../Docs/Building-Review.md) is in `Docs/`
in a full repository checkout. It is optional when copying this package alone.
This is a static, estimated environment; elevator travel is a camera change.
