# Documentation archive

These files preserve the project's earlier plans, sources and decisions.
Use the [active project plan](../Project-Plan.md) for current work and the
[building review guide](../Building-Review.md) for the model. Dates, sign-offs
and implementation claims in archived sources describe their original context.
They are not open alternatives to current decisions. Dennis's October 26 review
approved The Journey, Check-In Console, checklist-first demo scope, immediate
advancement on correct answers, restatement after the first incorrect submission,
stronger help offered after the second, starting energy 10 and cost 1 per
incorrect submission. The active plan owns those rules; original attachments
remain unchanged even where they use older names or retry counts.
